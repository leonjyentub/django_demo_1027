# 大學選課系統

## 專案簡介

本專案為一個簡易的大學選課、加課、退選與個人課表管理系統，採用 Django 6.1.2 開發，提供學生、教師與管理員三種角色，並以 Bootstrap 5 打造簡潔明亮的大學風格介面。

## 主要功能

- **使用者角色管理**：支援學生（student）、教師（teacher）、管理員（admin）三種角色
- **課程瀏覽**：課程列表以卡片方式呈現，顯示課程代碼、名稱、教師、學分、上課時間、地點、容量等資訊
- **學期篩選**：可依學期篩選課程列表
- **線上加選**：學生可在課程列表點選加選課程（系統會檢查課程容量）
- **線上退選**：學生可於「我的課表」頁面退選已選課程
- **個人課表管理**：提供「已選課程」清單與「每週課表」視圖，清楚顯示各時段課程安排
- **管理後台**：透過 Django Admin 管理使用者、課程、開課時段、選課紀錄

## 技術架構

- **後端框架**：Django 6.1.2
- **程式語言**：Python 3.14.7+
- **前端框架**：Bootstrap 5.3.3、Bootstrap Icons
- **資料庫**：SQLite（預設）
- **套件管理**：uv

## 安裝與執行

### 1. 安裝相依套件

```bash
uv sync
```

### 2. 執行資料庫遷移

```bash
python manage.py migrate
```

### 3. 建立管理員帳號

```bash
python manage.py createsuperuser
```

### 4. 啟動開發伺服器

```bash
python manage.py runserver
```

啟動後可開啟以下頁面：

- **課程列表**：http://127.0.0.1:8000/
- **登入頁面**：http://127.0.0.1:8000/accounts/login/
- **我的課表**：http://127.0.0.1:8000/timetable/（需登入且為學生身分）
- **管理後台**：http://127.0.0.1:8000/admin/

## 使用說明

1. 於管理後台新增教師帳號（角色設為 `teacher`）與學生帳號（角色設為 `student`）
2. 新增課程（Course）並指定授課教師
3. 新增開課時段（Course Offering），設定學期、星期、上課時間、地點、容量
4. 學生登入後即可於課程列表加選課程，並於「我的課表」查看或退選

## 注意事項

- 僅**學生**身分可使用加選、退選及查看個人課表功能
- 加選時會檢查課程容量，額滿時無法加選
- 選課紀錄採用唯一約束（同一學生不可重複加選同一開課時段）
- 時區設定為 `Asia/Taipei`，語系設定為繁體中文
